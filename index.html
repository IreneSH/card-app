匯出備份

資料主檔在你的 GitHub repo（cards.json），匯出功能用於額外備份或給 Excel 使用。

批次匯入

支援 JSON 陣列。大量建檔：在 Claude 對話中分批上傳名片照片，請 Claude 整理成以下欄位的 JSON 後匯入：nameZh, nameEn, companyZh, companyEn, title, officePhone, ext, mobile, email, address, category, notes（category：上市公司／同業／業務／記者／其他）

① 雲端資料儲存（GitHub）

名片文字資料存在你自己的 GitHub private repo，任何裝置登入設定後都能同步。首次設定：
1. GitHub 建一個 private repo（例如 card-data，跟放這個網頁的 repo 分開）
2. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
3. Repository access 只勾選 card-data；Permissions → Contents → Read and write
4. 把 token 貼到下方。每支裝置設定一次即可。

② AI 辨識（Anthropic）

填入 API key 後可拍照直接辨識；「⇅」的 JSON 匯入永遠可用，兩種方式並存自由選。key 到 console.anthropic.com 申請。
